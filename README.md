# QR Iventariado - Aplicación Android para el contol de stock de equipos infromárivos

## Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instaladas las siguientes herramientas:

- **Java JDK 21+**
- **Android Studio Narwhal recomendable**
- **Android API 36**


## Configuración del proyecto

### Paso 1 — Clonar el repositorio

```bash
git clone git@github.com:DannyIwakura/qr-inventariado.git
cd qr-inventariad
```

### Paso 2 — Importar el proyecto

Impota el proyecto al IDE de preferencia, Gradle debería instalar las depecncias una importado, si no es así, en Adroind Studio ve a Build -> Clean Proyect luego Build -> Asemble Proyect
